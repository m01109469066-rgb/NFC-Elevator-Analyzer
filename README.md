NFC ELEVATOR ANALYZER V2

An Android application for exploring and analyzing publicly available NFC information.

Features

- NFC availability and status check
- NFC tag detection
- Public NDEF data reading
- Local scan history
- Black and gold user interface
- Offline functionality for core features

Privacy

Scan history is stored locally on the device.

Build

The Android APK is built automatically using GitHub Actions.

Disclaimer

This application is for NFC information analysis and educational purposes. It does not clone access cards, extract security keys, or bypass access-control systems.
